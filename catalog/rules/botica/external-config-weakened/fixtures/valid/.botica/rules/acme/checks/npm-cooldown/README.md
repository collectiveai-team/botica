## Directive

npm installs only packages released at least seven days ago.

## Why

The project runs the check of npm with the setting that the rule names.

## Tool

npm reads the setting from `.npmrc`.

## Configuration

The fragment in `config/.npmrc`.

## Do

The value of the fragment, or a stricter one.

## Don't

A weaker value without its reason.

## Suppression

Switch the rule off in the configuration of botica.
