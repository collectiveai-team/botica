## Directive

uv resolves only packages released at least seven days ago.

## Why

The project runs the check of uv with the setting that the rule names.

## Tool

uv reads the setting from `pyproject.toml`.

## Configuration

The fragment in `config/pyproject.toml`.

## Do

The value of the fragment, or a stricter one.

## Don't

A weaker value without its reason.

## Suppression

Switch the rule off in the configuration of botica.
