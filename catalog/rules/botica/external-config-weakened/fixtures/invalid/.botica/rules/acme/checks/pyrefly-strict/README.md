## Directive

pyrefly checks a Python project with its strict preset.

## Why

The project runs the check of pyrefly with the setting that the rule names.

## Tool

pyrefly reads the setting from `pyproject.toml`.

## Configuration

The fragment in `config/pyproject.toml`.

## Do

The value of the fragment, or a stricter one.

## Don't

A weaker value without its reason.

## Suppression

Switch the rule off in the configuration of botica.
