# Use

Botica is a single binary, published on PyPI as a wheel that needs no Python at run time:

=== "Bash"

    ```bash
    uv tool install botica     # keep it installed
    uvx botica lint            # or run it once, without installing
    ```

The [manual](https://github.com/collectiveai-team/botica/blob/main/docs/botica.md) covers the
commands, the configuration, how to silence a finding, the editor and the hooks of prek.
